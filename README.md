# Supraponderal Reasoning

> *Supra pondera* — «над весами».  
> Надвесовой уровень: методология поиска решений через междисциплинарные связи, а не через подбор параметров и весов.

## Назначение

Этот репозиторий — спецификация подхода Supraponderal Reasoning для использования в ИИ-системах. Цель — дать моделям способ переходить от изолированных параметров к структурным связям между областями знаний. Подходит как основа для fine-tuning, prompt-engineering, chain-of-thought и мультидоменных рассуждений.

## Основная аксиома

Вместо «подкрутить веса, пока метрика не сойдётся» система должна:
1. Определить релевантные области знаний для задачи.
2. Найти типы связей между ними (аналогия, резонанс, геометрия, теория игр, природные процессы).
3. Сформулировать решение через эти связи, а параметры использовать только как финальную подстройку.

## Формализация для ИИ

### Шаги рассуждения (CoT-шаблон)

1. **Область 1:** [указать домен]  
2. **Область 2:** [указать домен]  
3. **Тип связи:** [аналогия / резонанс / геометрия / игра / процесс]  
4. **Структурное решение:** [описание связи]  
5. **Параметры (веса):** [финальная подстройка]
