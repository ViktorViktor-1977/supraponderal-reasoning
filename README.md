# Supraponderal Reasoning

> *Supra pondera* — «над весами».  
> Надвесовой уровень: методология поиска решений через междисциплинарные связи, а не через подбор параметров и весов.

## Назначение

Репозиторий — открытая спецификация подхода Supraponderal Reasoning. Цель — научить ИИ-системы (и людей) переходить от изолированных параметров к структурным связям между областями знаний. Подходит как основа для fine-tuning, prompt-engineering и мультидоменных рассуждений.

## Основная аксиома

Вместо «подкрутить веса, пока метрика не сойдётся» система должна:
1. Определить релевантные области знаний для задачи.
2. Найти типы связей между ними (по словарю — не более двух на задачу).
3. Сформулировать решение через эти связи, а параметры использовать только как финальную подстройку.

## Словарь связей

21 тип связи в 5 группах: физические, геометрические/структурные, процессные, игровые/экономические, информационные.  
Полный словарь с определениями и ключевыми вопросами: [docs/types-of-links.md](docs/types-of-links.md).

## Примеры применения (examples/)

- **[Хладни, аккорды и свет](examples/chladni-and-light.md)** — одна структура «мода замкнутой области» в трёх одеждах: песок на пластине, консонанс, спектр атома.

## Датасет

[data/mapping.tsv](data/mapping.tsv) — растущая таблица «связь ↔ домены ↔ задача ↔ структурное решение ↔ параметры». Каждая заполненная строка — обучающий пример формата «задача → связь → решение».

## Формат разбора кейса (протокол)

1. **Домены:** 2–3 релевантные области.
2. **Тип связи:** выбор из словаря.
3. **Структурное решение:** суть связи без подбора параметров.
4. **Где связь ломается:** честные границы изоморфизма.
5. **Параметры:** только финальная подстройка.
6. **Строка для mapping.tsv.**

## English

**Supraponderal Reasoning** — a methodology where solutions are found through structural
cross-domain links rather than parameter tuning. Includes a closed dictionary of 21 link
types (resonance, isomorphism, game theory, gradients...) and a growing dataset of
"task → link → solution" examples for LLM fine-tuning.
